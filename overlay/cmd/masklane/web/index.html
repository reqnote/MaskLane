Kiro を MaskLane 経由で起動する

  1. Kiro が起動していたら完全に終了します。
  2. 下のコマンドをコピーし、Windows の PowerShell に貼り付けて実行します。
  3. 「通信・キーワード」でキーワードを登録し、その語を Kiro のチャットで送信します。「最近の通信」で結果を確認します。
